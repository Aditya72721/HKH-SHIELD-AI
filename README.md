# HKH SHIELD AI

Historical replay of 3 Himalayan disasters using public data:
Nepal Rasuwa 2026, Kedarnath 2013, Sikkim 2023.

**This is a research prototype. It did not predict any of these events.**

The risk model is a prototype scoring model trained on a compiled dataset
(3 documented case rows, 27 literature rows, 440 sampled rows).
It is NOT a validated predictor. Do not use it for real decisions.

Open `hkh-shield-ai_cases.html` in a browser (internet needed for map tiles).
